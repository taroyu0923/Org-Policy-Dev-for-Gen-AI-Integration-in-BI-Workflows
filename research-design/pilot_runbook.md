## What the pilot is for

One full run of protocol v0.98 with a Chinese-speaking breadth participant (#5 or #6), held in Taiwanese Mandarin, so that no Depth A informant is spent. It tests three things:

1. **Wording:** do the fixed zh-TW items work when read aloud (wording card §1–§8)?
2. **Timing:** does the protocol fit 60–75 minutes, with Section B protected?
3. **Coverage:** do the questions produce answers to the main RQ, SQ1 (downward) and SQ2 (upward)?

The protocol's original target (pilot by Oct 3) has passed; the depth interviews wait on the pilot.

## 2. During (60–75 min)

- Opening → A → B (core) → C → D → E → G, as in the protocol. Opening item 3 now means "consent form v1.1 received (signed or by email reply)", not "information sheet read".
- Read every fixed item word for word. If one has to be rephrased on the spot, note what was actually said; if it was misunderstood, note what was heard. This is the main output of the pilot.
- Never say 幻覺、違規、出錯、犯錯、失誤 (hallucination, violation, mistake) unless the participant does.
- Sensemaking check: note whether *who they talked the rule over with* comes up without a probe. If not, ask the live follow-up after B2: 「在決定怎麼做之前，你有跟誰討論過嗎？」
- Note the start time of each section. If B runs long, protect B and cut from C–E (protocol §11).
