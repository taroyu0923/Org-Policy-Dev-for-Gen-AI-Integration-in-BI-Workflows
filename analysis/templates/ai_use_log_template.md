# AI use log

> Created Oct 9, 2026. One line per use of a third-party AI tool on **interview material** (transcripts, memos, contact summaries, coded extracts). Store the filled log in OneDrive (`Thesis-Interviews/ai_use_log.md`), not in the repo. Use participant numbers only.
>
> **Rule (supervisor, Oct 6; consent form v1.1):** de-identified material only. Recordings never leave Teams. Every output is checked by the researcher; coding decisions stay with the researcher. Uses on non-interview material (literature, chapter drafts, codebook definitions) do not go here; Chapter 3.7 covers those.

## Before each use: de-identification check

Tick on the copy you are about to use. If any box cannot be ticked, do not use the tool.

- [ ] Participant's name and any nicknames removed
- [ ] Colleagues' names and job titles that identify a person removed
- [ ] Organisation name, parent company and brand names removed
- [ ] Team, department and office names removed
- [ ] Product, tool-internal and project names removed (generic tools such as "ChatGPT" or "Copilot" may stay)
- [ ] Dates generalised (e.g. "early 2024"), unless the date itself is needed and cannot identify anyone
- [ ] Locations below country level removed
- [ ] Copy saved as `P<nn>_deid_<part>` and kept apart from the identifiable transcript
